# Assets and licenses

Rule: nothing from Quake 3's `pak0.pk3` (or any other proprietary pack) is ever committed or shipped.
Every file in `data/` must be listed here with its source and license.

| File | Source | License |
|---|---|---|
| `data/base/default.cfg` | Original | GPLv2-or-later |
| `data/base/gfx/2d/bigchars.tga` | Generated by `tools/gen_placeholder_assets.py`, glyphs rendered from Fira Code Regular | Fira Code: SIL OFL 1.1 (https://github.com/tonsky/FiraCode) |
| `data/base/console.tga` | Generated (gradient) | GPLv2-or-later |
| `data/base/white.tga` | Generated (solid white) | GPLv2-or-later |
| `data/base/sound/feedback/hit.wav` | Generated (synthesized tick); also the engine's required default sound | GPLv2-or-later |
| `data/base/textures/skaar/grid_*.tga` | Generated dev-grid textures | GPLv2-or-later |
| `data/maps-src/*.json` | Original map sources, compiled by `tools/mapc` | GPLv2-or-later |

Regenerate: `python3 tools/gen_placeholder_assets.py` (needs `pip install pillow`).

## Candidate free sources (to check per file before use)
- OpenArena: game data is mostly GPLv2, but some files have other licenses. Check each file's credits before importing.
- Kenney.nl: CC0 textures and sounds.
- Freesound: check that each sound is CC0 or CC-BY, and keep the attribution here.
